# Social Media Analytics Tool

A comprehensive analytics dashboard for monitoring and optimizing your social media presence across multiple platforms.

## Features

- Interactive dashboard with real-time metrics and visualizations
- Platform-specific analytics for major social networks
- Audience demographic insights and engagement tracking
- Content performance analysis with historical comparisons
- Trend identification and sentiment analysis
- Customizable reporting with export options
- Campaign tracking and ROI measurement

## Technology Stack

- **Frontend**: React with TypeScript
- **Styling**: Tailwind CSS
- **Charts**: Recharts
- **Animations**: Framer Motion
- **Backend**: Node.js with Express
- **Icons**: Lucide React

## Getting Started

1. Install dependencies:
   ```
   npm install
   ```

2. Start the development server:
   ```
   npm run dev
   ```

3. In a separate terminal, start the backend server:
   ```
   npm run server
   ```

## Project Structure

- `/src/components` - Reusable UI components
- `/src/pages` - Page components for different sections
- `/src/utils` - Utility functions and helpers
- `/server` - Backend Express server
